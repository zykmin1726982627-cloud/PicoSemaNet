# 最终消融补充队列说明

## 目标与顺序

队列严格按用户指定的1–5顺序运行。由于第3项包含无KD和无Edge两个独立因子，实际共6次训练：

1. `s1_budget_matched_fullpath_seed42`：主模型在100轮上限、20轮耐心下的预算匹配参考；
2. `s2_no_fullpath_seed43`：M2无FullPath只补一个随机种子（Seed 43）；
3. `s3a_no_distill_seed42`：最终NDS主模型移除KD；
4. `s3b_no_edge_seed42`：最终NDS主模型移除Edge loss；
5. `s4_learned_head_fullpath_seed42`：固定语义通道改为普通可学习`1x1`辅助头；
6. `s5_encoder_semantic_seed42`：只在E1–E4和瓶颈保留固定语义监督，移除解码路径监督。

## 公平性控制

- 所有运行使用同一锁定的70/10/20数据划分、320分辨率和batch size 8；
- 推理主干均为同一个4,844参数PicoLite core；
- 所有语义头只存在于训练阶段，不进入正式推理图；
- 普通可学习头可混合每阶段的全部特征通道，训练参数5,123，比固定通道版的4,928更多，但两者推理参数均为4,844；
- 第1项使用100/20预算，其余关键方法消融使用与原主模型一致的200/40预算；
- 数据加载workers统一设为8，增强仍按Seed、epoch和样本索引确定生成。
